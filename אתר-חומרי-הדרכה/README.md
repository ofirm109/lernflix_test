## מה נשאר לעשות — שלב אחד

העלה את **כל התיקייה הזו** ל-GitHub Pages, כשמבנה הקבצים נשמר:

```
index.html
assets/tavnit-ipion.docx
```

זהו. אין מה להגדיר ואין מה לערוך.

> **חשוב:** התיקייה `assets` והקובץ שבתוכה חייבים לעלות יחד עם `index.html`.
> האתר מוסר לסקריפט את הכתובת שלו בזמן ריצה, ולכן זה יעבוד עם **כל שם מאגר** שתבחר.

## איך לבדוק שהכול עובד

1. פתח את כתובת האתר החדשה.
2. הזן את כתובת המייל שלך ולחץ **"שלחו לי את החומרים"**.
3. אמורה להופיע הודעת "המייל בדרך אליכם", והמייל יגיע תוך שניות.

אם מופיעה השגיאה *"הקובץ המצורף אינו זמין כרגע"* — סימן שהתיקייה `assets` לא עלתה, או שהיא נמצאת במקום אחר.

- כותרת: `חומרי הדרכה: מערכת שבץ-נא ותבנית אפיון כלי AI`

**הגנות מובנות:**

- אימות תקינות כתובת המייל בצד הלקוח ובצד השרת
- חסימת שליחה כפולה לאותה כתובת בתוך דקה
- קבלת בקשות רק מדומיינים של `github.io`
- שמירת הקובץ המצורף במטמון ל-6 שעות (מהירות ועמידות לתקלות רשת זמניות)
