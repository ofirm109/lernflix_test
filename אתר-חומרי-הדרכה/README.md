# אתר חומרי הדרכה

דף אחד שמציג את החומרים מהמפגש ומאפשר לקבל אותם בשלוש דרכים — **כולן ללא מגבלת כמות**.

האתר **אינו משתמש בשום שירות של גוגל ובשום שרת.** הוא קובץ HTML סטטי בלבד.

---

## מה יש בדף

| פעולה | מה קורה | מגבלה |
|---|---|---|
| **שליחת הקישור לעצמי במייל** | נפתחת תוכנת המייל של המשתמש עם הודעה מוכנה. הוא שולח לעצמו, מהחשבון שלו | **אין** |
| **פתיחת המערכת** | מעבר ישיר למערכת שבץ-נא | **אין** |
| **הורדת הקובץ** | הורדת תבנית האפיון ישירות מ-GitHub Pages | **אין** |

זה עובד ל-500 איש בו-זמנית באותה מידה שזה עובד לאחד.

צריך להעלות **קובץ אחד בלבד**:


## איך "שליחה לעצמי" עובדת

הכפתור הוא קישור `mailto:` — תקן ותיק שכל תוכנות המייל תומכות בו. לחיצה פותחת הודעה חדשה בתוכנת המייל של המשתמש, עם הכותרת והגוף כבר מוכנים. הוא מזין את הכתובת שלו ושולח.

**המשמעות:** ההודעה יוצאת מהחשבון של המשתמש, לא ממך. שום שרת לא מעורב, ולכן אין מה להגביל.

**מה ההודעה מכילה — קישור אחד בלבד:**

```
נושא: חומרי הדרכה: מערכת שבץ-נא ותבנית אפיון כלי AI

לקבלת החומרים מההרצאה:
https://ofirm109.github.io/lernflix_test/אתר-חומרי-הדרכה/
```

הקישור מוביל חזרה לדף הזה, ומשם המשתמש מגיע לשני החומרים. זו הסיבה שההודעה קצרה ונקייה — במקום רשימת קישורים ארוכה שנראית עמוסה בתוך תוכנת המייל.

**סייג אחד שכדאי להכיר:** זה תלוי בתוכנת מייל מוגדרת במכשיר. בנייד זה עובד כמעט תמיד. במחשב ללא תוכנת מייל מוגדרת (מישהו שמשתמש רק בג'ימייל בדפדפן) ייתכן שלא יקרה כלום — ולכן כפתורי הגישה הישירה נמצאים שם כגיבוי.

## שינויים עתידיים

הכול נמצא ב-`index.html`:

| מה לשנות | איפה בקובץ |
|---|---|
| כתובת מערכת שבץ-נא | ה-`href` של `id="sysLink"` |
| כתובת תבנית האפיון | ה-`href` של `id="docLink"` |
| כתובת הדף עצמו (לשליחה במייל) | `SITE_URL` בתוך ה-`<script>` |
| נוסח המייל | `subject` ו-`body` בתוך ה-`<script>` |
| פרטי הקשר | בלוק `class="contact"` בסוף ה-HTML |
| טקסטים ועיצוב | גוף ה-HTML וה-`<style>` |

> **שים לב:** אם תעביר את הדף לכתובת אחרת — צריך לעדכן גם את `SITE_URL`, אחרת המייל ימשיך להפנות לכתובת הישנה.
