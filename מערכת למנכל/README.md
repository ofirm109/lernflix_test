# מתרגם חי · ספרדית ← עברית

מערכת שמאזינה לדיבור בחדר בספרדית ומציגה תרגום חי לעברית על המסך.
ללא התקנה, ללא עלות, ללא הרשמה.

זיהוי הדיבור מתבצע במנוע של Chrome עצמו; הטקסט נשלח לתרגום ומוצג בעברית,
מחולק לפסקאות לפי הפסקות בדיבור. התמליל המלא נשמר ברקע.

## שתי דרכים להריץ

### 1. מקומית (מומלץ) — Windows
לחיצה כפולה על `START.bat`. הוא מרים שרת מקומי (Node.js אם מותקן, אחרת
PowerShell המובנה בווינדוס) ופותח את Chrome על `http://localhost:8765`.

יתרון: התמלילים נשמרים אוטומטית לתיקייה `transcripts/` שליד הקבצים.

### 2. כאתר — GitHub Pages
```
Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
```
תוך דקה האתר יהיה זמין ב-`https://<user>.github.io/<repo>/`.

`index.html` הוא עצמאי לחלוטין ולא דורש שרת: כשאין שרת מקומי הוא פונה
ישירות לשירות התרגום. מיקרופון עובד כי GitHub Pages מוגש ב-HTTPS,
והרשאת המיקרופון נשמרת לצמיתות לאותה כתובת.

הבדל יחיד: אין כתיבה אוטומטית לדיסק. התמליל נשמר בזיכרון הדפדפן,
וכפתור **שמור** מוריד אותו כקובץ HTML.

> הקבצים באתר ציבורי הם רק קוד המערכת. שום תמליל, הקלטה או מידע אישי
> לא נשמר בשרת — הכול נשאר בדפדפן שלך.

## דרישות
Google Chrome (או Edge) + חיבור אינטרנט.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | כל המערכת — ממשק, זיהוי דיבור, תרגום |
| `START.bat` | הפעלה בלחיצה כפולה ב-Windows |
| `server.js` | שרת מקומי (Node.js) — פרוקסי תרגום ושמירת תמליל |
| `server.ps1` | אותו שרת ב-PowerShell, למקרה שאין Node.js |
| `transcripts/` | התמלילים שנשמרים אוטומטית |
